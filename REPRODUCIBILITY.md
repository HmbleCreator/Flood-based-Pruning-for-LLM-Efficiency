# FLOOD-Based Pruning for LLM Efficiency — Reproducibility Package

This package reproduces the empirical results behind the three-paper trilogy:

1. **Invisible Bridges** (`paper/invisible_bridges.tex`)
   Which attention heads matter? Discovers low-weight "bridge" heads missed by Wanda.
2. **Conserved Perturbation Geometry** (`paper/conserved_perturbation_geometry.tex`)
   How does influence propagate? Shows perturbations collapse onto a shared low-dimensional subspace.
3. **Estimating Routing Importance** (`paper/estimating_routing_importance.tex`)
   Can routing topology predict causal importance? RIE centralities explain up to 80% of
   perplexity damage; FLOOD pruning preserves perplexity 31x better than magnitude pruning.

## Environment

Python 3.10+ (tested on 3.10/3.11). CPU suffices for all analyses except the
dependency-matrix extraction, which benefits from one GPU. See `requirements.txt`.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Local model weights are expected under `gpt2_local/` and `gpt2_medium_local/`
(GPT-2 Small / Medium). Other models load from the HuggingFace cache.

## Run order

Each stage reads cached `.npy` arrays when present; delete them to force recompute.

### Paper 1 — Invisible Bridges (`src/phase0` … `src/phase4`)
| Order | Script | Produces |
|-------|--------|----------|
| 1 | `src/phase0/phase0exp.py` | Bridge scores per head (Wanda vs. Bridge correlation) |
| 2 | `src/phase1/phase1_ablation.py` | Ablation damage ratios (candidates vs. controls) |
| 3 | `src/phase1/phase1_5_confounders.py` | Layer-0 / attention-sink confounder checks |
| 4 | `src/phase2/phase2_prediction.py` | Prospective prediction (H09) |
| 5 | `src/phase3/phase3_mechanistic.py`, `src/phase3/phase3b_h07_vs_h09.py` | Amplification, entropy, per-token maps |
| 6 | `src/phase4/phase4_closing.py` | Domain-conditional scores |

### Paper 2 — Conserved Perturbation Geometry (`src/paper2_dependency`)
| Order | Script | Produces |
|-------|--------|----------|
| 1 | `map_dependencies.py` | Per-layer influence + CKA matrices (bridge vs. control) |
| 2 | `map_all_layers.py` / `map_all_layers_generalized.py` | SVD spectrum, subspace alignment across layers |
| 3 | `compare_bridge_control_geometry.py` | Gini / PR / cumulative-variance comparison |

### Paper 3 — Estimating Routing Importance (`src/flood` + `src/paper3_routing`)
| Order | Script | Produces |
|-------|--------|----------|
| 1 | `src/paper3_routing/extract_dependency_graph.py` | Dependency graph, PageRank, communities, edge betweenness |
| 2 | `src/flood/score.py` | `compute_routing_importance_scores` (RIE centralities) |
| 3 | `src/flood/run_damage_regression.py` | OLS target: causal damage per head |
| 4 | `src/flood/run_layer_controlled_regression.py`, `run_nested_regression.py`, `run_negative_control.py` | Layer control, nested F-tests, shuffle baselines |
| 5 | `src/flood/run_statistical_tests.py`, `test_role_significance.py`, `run_transfer_diagnostics.py` | Holm-Bonferroni, role-overlap permutations, OOD transfer |
| 6 | `src/flood/benchmark.py`, `multiseed_validation.py` | Perplexity sweeps (multi-seed), fine-tuning recovery |
| 7 | `src/flood/prune.py`, `evaluate.py` | FLOOD / magnitude / random masking + topology preservation |

## Cached data

167 `.npy` arrays at the repo root hold all intermediate matrices (dependency graphs,
centrality scores, causal-damage vectors, prompt-level residuals). `git lfs` is recommended
if these are tracked; they are optional for re-running because every script regenerates them.

## Figures

116 PNGs in `paper/figures/` are generated by the scripts above and embedded in the three papers.

## Reproducing the papers

```bash
cd paper && pdflatex estimating_routing_importance.tex   # x3 passes
          pdflatex invisible_bridges.tex
          pdflatex conserved_perturbation_geometry.tex
```
Verified to compile on Overleaf (TeX Live 2023+, `natbib`, `algorithm2e`, TikZ).
