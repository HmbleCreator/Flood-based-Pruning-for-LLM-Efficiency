# Flood-based Pruning for LLM Efficiency

> **Flood** is an ongoing research program investigating structural importance in transformer networks and its application to efficient pruning.

---

## Research Roadmap

*   **[v1.0] Invisible Bridges (Paper 1)**: Discovery of structurally critical attention heads and downstream sensitivity analysis.
*   **[Planned] Flood Pruning (Paper 2)**: Designing a bridge-guided pruning algorithm.
*   **[Planned] Adaptive Bridge Recovery (Paper 3)**: Researching bridge-guided recovery and network compression.
*   **[Planned] Scaling to Modern LLMs**: Extending findings to larger open-source models (e.g., Llama, Mistral, Gemma).

## Getting Started

### Installation

Clone the repository and install dependencies:

```bash
pip install torch transformers numpy matplotlib
```

### Running Experiments

To reproduce the results of different phases:

```bash
# Phase 0: Metric Independence
python src/phase0/phase0exp.py

# Phase 1: Targeted Ablation
python src/phase1/phase1_ablation.py

# Phase 1.5: Confounder Elimination
python src/phase1/phase1_5_confounders.py

# Phase 2: Prospective Prediction
python src/phase2/phase2_prediction.py

# Phase 3: Mechanistic Analysis
python src/phase3/phase3_mechanistic.py

# Phase 3b: Head 7 vs Head 9
python src/phase3/phase3b_h07_vs_h09.py

# Phase 4: Closing Experiments (Domain-Conditional & Amplification)
python src/phase4/phase4_closing.py
```

*Note: The scripts will automatically fall back to loading the model weights locally if `gpt2_local` or `gpt2_medium_local` exist in the repository root. Otherwise, they will download the weights from Hugging Face.*
